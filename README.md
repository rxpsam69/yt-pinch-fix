\# YouTube — Restore Native Pinch-to-Zoom



Fixes YouTube's pinch-to-zoom gesture hijack and restores native browser zoom behavior.



\## What it does

\- Blocks YouTube wheel/pinch event interception

\- Restores native trackpad pinch-to-zoom



\## Install



Click this link to install in Violentmonkey:



https://raw.githubusercontent.com/rxpsam69/yt-pinch-fix/main/youtube-pinch-fix.user.js



\## Compatibility

\- Violentmonkey

\- Tampermonkey

\- Chrome / Edge / Firefox
